# 主题诗与内容创作

同学会/聚会方案常配一首主题诗（放在 header 后的固定卡片里），并配白话解题与标语徽章。这部分最能体现"用心"，但也是有明确套路可循的。

## 主题诗

### 形式
- 七律（四联八句）最常见，押平水韵或宽韵即可；本次用川/边/天/筵。
- 内容层次：起句点"昔日分别"，承句写"今日重逢"，转句抒怀，合句祝将来。
- 标题要通俗（如《鹏城聚首》优于生僻的《鹏城喜晤》）。

### 素材来源
- 城市别称入诗：深圳=鹏城、天津=津门、广州=羊城/穗。
- 结合出行时点：如"亚太盛会初歇后"点出 APEC 刚结束（见 `references/hotspots.md`）。
- 结合周年：如"鹏城暂别君须记，明年津门再开筵"——这次小聚、明年 30 周年。
- 诗句风格可按用户偏好调整：本次先李白风（明月/金樽/长风/放歌），后改通俗版。

### 配套元素
- **白话解题**：一两句，把诗里的地名、事件、祝愿讲清楚（"羊城一别，今朝鹏城再会…"）。
- **标语徽章**：4 枚短标语，如"欢度时光/畅聊今昔/鹏程万里/同窗情深"，用 `.slogan span` 样式。
- **周年口径**：务必确认是"这次"还是"明年"，别写错（本次踩过坑）。

### 样式
- 深蓝渐变卡片 `.poem`，深浅主题下都要精致。
- 桌面端居中显示（header 与 poem 居中，正文左对齐）。

## 温馨提示（紧要项）

- 只放**最紧要的 3–5 条**，不堆常规项。典型：天气穿衣最低温、场馆预约规则、周年仪式感（带旧照）、返程衔接。
- 用 `.note` / 列表，一条一事。

## 全程一览表

- 列：日期/时间、地点、安排与看点、交通衔接、停留。
- 两条可选路线分开成组，只在分组首行标线别（如"前海线 09:00–12:30"），后续行用 `↳` 缩进，避免每行重复线别。
- 可选点单独成行并标"可选/视时间而定"，不要夹在其他行文字里。
- 时间段统一；具体午餐时刻可保留差异。

## 亮点/话题/看点的写法

- 用 `.kv`（亮点/交通/话题）或 `.line`（看点/话题/交通/返程）组织，标签金色加粗。
- 内容要有"信息量 + 人情味"：既有事实（距离、地铁口），也有故事（品牌起源、城市记忆）。
- 每条聚焦，不在多处重复同一信息。
