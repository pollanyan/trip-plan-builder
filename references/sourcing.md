# 素材与价格搜集（小红书 / 大众点评 / 携程 / 飞猪）

出行方案的可信度取决于**真实图片 + 真实价格**。本文件记录从内容平台取图、从 OTA 查价的实测做法与坑。制作方案前先读本文件。

## 一、平台分工

| 平台 | 主要用途 | 备注 |
|---|---|---|
| **小红书** | 餐厅/景点的近期真实实拍、口碑、打卡热点 | 需登录；图片多为手机竖拍，注意剔除商家广告图 |
| **大众点评** | 餐厅评价数、人均、菜系、包厢信息 | 需登录；默认城市可能不对，务必切到目标城市 |
| **携程** | 酒店真实房价（会员价）、酒店外景/客房实拍图 | 查价与取图都需登录；相册图走公开 CDN |
| **飞猪** | 酒店价格交叉核验 | 覆盖不全、连续搜索易触发验证码 |
| **去哪儿/同程** | 价格的搜索引擎快照参考 | 直连常跳登录或报账号异常，不宜作为唯一来源 |

原则：**价格至少两平台交叉核验**；单一平台的"起价"可能是错误关联房型，不可直接采信。

## 二、浏览器工具

用 `chrome-devtools` CLI 操作已登录的浏览器会话（用户提前登录各平台）：

```
CHROME_DEVTOOLS=/Users/yanbl/.workbuddy/binaries/node/versions/22.22.2-6/bin/chrome-devtools
$CHROME_DEVTOOLS new_page "<url>"
$CHROME_DEVTOOLS take_snapshot <pageId>
$CHROME_DEVTOOLS evaluate_script "<js>" --pageId <id>
$CHROME_DEVTOOLS take_screenshot <pageId>
```

本机 Chrome 沙箱初始化失败，需用有头模式并传 `--chromeArg=--no-sandbox`（等号形式，yargs 才吃进去）。

## 三、小红书取图（重要坑）

- **必须登录**：未登录拿不到完整图片与笔记。
- **第一步先检查登录态**：打开小红书搜索页，读 `document.body.innerText`。
  - 出现"登录后查看搜索结果"且笔记卡片数=0 → 会话已失效。
- **登录态失效时：立即暂停，请用户登录**（最高优先级规则，见 SKILL.md）：
  1. 明确告诉用户"小红书登录已失效，请扫码登录"，并停下当前操作。
  2. **在用户明确确认已登录前，不执行任何依赖小红书登录态的步骤**，也不要自动改用其它来源顶替。
  3. 用户确认登录后，**先验证登录态**（读页面文字/笔记卡片数），确认有效再从暂停处继续取图；不要仅凭口头确认就抓取。
  4. 若任务还需要携程/飞猪/大众点评登录，主动打开这些平台的登录入口，方便用户一次性登录；逐个验证通过后再用其数据。
  5. 只有用户明确表示"不登录，用公开信息即可"时，才改用公开搜索或开放图库（Wikimedia Commons API），并在方案里如实标注图片来源，不冒充小红书实拍。
- **300017 安全限制**：直接打开 `/search_result/<id>`（无 `xsec_token`）会触发安全拦截。
  **正确做法**：从搜索结果页取带 `xsec_token` 的完整 href，再打开该链接。
- **筛选**：优先近 1 周—1 个月的笔记、赞数高的实拍；剔除商家自营软文图、无关图。
- **命名与核对**：下载后按 `序号_店名_内容.webp` 命名，逐张用看图工具核对内容再入选。
- 竖图/方图混用正常，后续用 `scripts/normalize_images.py` 统一比例。

## 四、大众点评取数

- 默认城市可能不是目标城市（实测默认扬州），先切 cityId（深圳 = 7）。
- 站内搜索框的 uid 需先 `take_snapshot` 拿到再操作。
- 记录：评价数、人均、菜系、片区、包厢/包房数。
- 人均口径要核对：同一品牌不同门店差异可能很大（如 ¥100 / ¥220 / ¥269）。

## 五、携程查价与取图

### 查价
- 列表页/移动端会跳 H5Login，需先从登录后的会话进入。
- 详情页 URL 格式（实测有效）：
  `https://m.ctrip.com/webapp/hotels/xtaro/detail?hotelid=<id>&atime=<入住日>&days=1`
- 登录后返回**会员价 / 挂牌价**两个数值；方案里用会员价，并中性表述为"携程会员价（已含平台优惠）"。
- **大坑**：搜索引擎快照或错误关联的"起价"可能离谱（实测某酒店误写 ¥590，实际会员价 ¥619、某平台标价 ¥1680）。**必须登录后逐家核对**，不要采信搜索快照。

### 取图
- 酒店相册页：`https://m.ctrip.com/webapp/hotel/album?hotelid=<id>&tab=0`（**必须带 `tab=0`**），点「房间」分类。
- CDN 图片 URL 规律（来自 `dimg04.c-ctrip.com`）：
  - 房型缩略图后缀 `_C_360_360_Q50.jpg`
  - 页头外景图后缀 `_W_1280_853_R5_Q70.jpg_.webp`
- 逐张看图核对，按「序号_酒店_外景/房间」存入 `hotel_photos/selected/`。

## 六、飞猪查价

- 可用搜索 URL（带日期与关键词）：
  `https://hotel.fliggy.com/hotel_list3.htm?city=440300&checkIn=<日期>&checkOut=<日期>&keywords=<关键词>`
- 覆盖不全（部分酒店搜不到）；连续搜索会触发验证码，不要硬刷。
- 用于与携程交叉核验，价格通常与携程会员价接近。

## 七、价格表述与隐私

- 价格一律标注"参考起价/会员价，周末浮动，以预订日为准"。
- **不要在方案里写平台账号昵称、会员等级、优惠券名称等隐私信息**，统一改为中性表述（如"携程会员价（已含平台优惠）/飞猪实时报价"）。
- 超预算的选项标注"升级·超预算"，不要直接删除或隐瞒。

## 八、素材入库流程

1. 分目录存放：`xhs_photos/`（小红书）、`hotel_photos/`（酒店）、`scene_photos/`（景点，含 `selected/` 精选）。
2. 每组图片先用 contact sheet 拼图快速核对，再逐张看图确认。
3. 精选图进入 `selected/`，用 `scripts/normalize_images.py` 统一比例。
4. 转 data URI 内嵌进 HTML（见 `references/workflow.md`）。
5. 方案里写清图片/价格来源口径（如"小红书近期实拍""携程会员价"），但不含隐私。

## 九、可信度提醒

- 品牌软文/测评稿里的数据（人均、包厢数、隔音分贝等）非官方菜单，**电话复核**后再写进方案。
- 用户明确要求"只给一家首推"时，对比项也要写清排除理由（片区、营业时间、人均口径差异等）。
