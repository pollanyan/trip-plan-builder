# 实战踩坑清单（务必先读）

这些是制作与反复修改出行方案时真实发生过的错误，按主题归类。动手前扫一遍可避免重复踩坑。

## 一、结构性错误（最严重，会导致版面错乱）

### 1. 删除内容时误伤父容器闭合
- **症状**：某章节内容"没向左右撑开"；邀请函/卡片跑到容器外；section 开 1 闭 2。
- **根因**：删 kv/残留时把 `</div>` 切错位置，导致 `.wrap`、`.card` 或 `.tl` 提前闭合。
- **做法**：每次删除后用浏览器查 DOM——`element.parentElement.className` 和 `section.querySelectorAll('.card').length`。父元素链错了一切样式都白调。
- **修复**：宁可**完整重建该 section**（用干净 HTML 一次写入），也不要在破损结构上继续打补丁。

### 2. 时间轴 `.tl` 提前闭合
- **症状**：某事件卡片下方出现大片空白（间距从正常 30px 变 133px）。
- **根因**：`.tl` 只包了前两个 `.ev` 就闭合，后面的 ev 暴露成 section 直接子元素。
- **做法**：出现"某块后大片空白"先查 `section.querySelectorAll('.tl').length` 和各 ev 的父元素，不要只盯单个 ev 的 padding。

### 3. <body> 后残留属性文本
- **症状**：页面顶部出现 `="xxxxx">` 乱码。
- **根因**：补 body 标签时留下了重复的属性尾巴。
- **做法**：改完 head/body 边界后检查 `</head>` 到 `<button>` 之间只有 `<body ...>` 一行。

### 3b. figure 级切片替换图组（曾造成最严重事故）
- **症状**：替换一个图组后，相邻事件块消失、整个 venue 章节不见、甚至文档被复制嵌套两份（body 出现两个）。
- **根因**：用 `s.rfind('<figure>')` + `find('</figure>')` 切片，跨越了图组边界吃到其他内容。
- **做法**：用图注/`<h3>` 做锚点，`rfind` 找最近的 `class="pics"` 起点，数出该组 `<figure>` 数量定位闭合，**整体替换 pics 块**；不要用 figure 级切片。
- 一旦结构错乱：浏览器 DOM 是唯一可靠判断（纯文本正则会误判）；从备份恢复或完整重建章节，别继续打补丁。

### 3c. 预览工具注入 data-page-node-id 导致替换失效
- **症状**：`s.count('<div class="kv">')` 明明该有却返回 0，替换不生效。
- **根因**：预览工具给元素注入了 `data-page-node-id="..."` 属性，纯字符串匹配不上。
- **做法**：用带 `[^>]*` 的正则匹配开标签，如 `<div[^>]*class="kv"[^>]*>`；替换范围要收窄，避免误删闭合标签。

## 二、视觉调整无效（先测量，再动手）

### 4. "没撑开"先查父元素，别盲调 max-width
- 曾反复调 `.wrap{max-width}` 都无效，最后发现 weather/venue/day1 在 `.wrap` 内、其余章节直接是 `BODY` 子元素——原始结构不一致。
- **做法**：浏览器 evaluate 打印各 section 的宽度与 `parentElement.className`，对照后再决定改哪。

### 5. 图片裁边 vs 留白的两难
- `object-fit:cover` + 固定高度会裁掉画面边缘（用户反感）；`contain` 又有大块留白。
- **正解**：文件层面把素材归一化到目标比例（模糊填充保留完整画面），再用 `cover` 显示。见 `scripts/normalize_images.py`。
- 不要靠 CSS 硬缩图来"省空间"，质量损失明显。

### 6. 编号样式不统一
- 圈号 ①–⑬ 在不同字体/尺寸下大小不一，与相邻文字不协调。
- **正解**：统一用简单数字 1–13，字号继承相邻文字；地图截图里只放纯数字，名称放图例。

## 三、内容与文案

### 7. 用户说"改了但没效果"多半是缓存
- 文件已改但右侧预览还是旧版时，用文件展示工具重新打开预览触发刷新；先用浏览器读 `document.body.innerText` 确认文件本身正确，再判断是不是缓存。

### 8. 地图按钮"点不动"
- 静态截图里的按钮是图的一部分，本来就不能点。
- **正解**：截图时隐藏按钮栏；明确告诉用户"要看可切换的真实地图请点下方链接"。

### 9. 强调样式要分类，不要一律加绿
- 打卡地人名/地名加粗绿；普通场所/店名加粗蓝。把非打卡地（如超级总部基地）也加绿会造成混淆。
- 末尾汇总表通常取消强调，用普通文字，与正文形成层次。

## 四、验证清单（每次改动后都跑）

用 Chrome DevTools CLI 打开 HTML，evaluate 检查：

```
- section 数量、card 数量、ev 数量是否符合预期
- 所有 data: 图片 complete && naturalWidth>0，broken=0
- document.documentElement.scrollWidth <= window.innerWidth+1（无横向溢出）
- 关键文字 innerText 是否包含/不包含（验证增删）
- 表格行数、图例项数
- 强调样式数量与颜色（如 .apec 数量、computedStyle.color）
- 卡片子元素是否单线排列（标签是否换行：height/lineHeight）
```

浏览器工具路径：`/Users/yanbl/.workbuddy/binaries/node/versions/22.22.2-6/bin/chrome-devtools`
常用命令：`new_page <url>`、`evaluate_script "<js>" --pageId N`、`take_screenshot N`、`resize_page N W H`。

## 五、同步与交付

- 每次改完 HTML **必须重新生成 MHTML**（`scripts/mhtml_pack.py`），否则两份文件不一致。
- 交付时两份一起呈现：HTML 主文件在前，MHTML 在后。
- 大文件（多图 base64）会有 2–4MB，属正常。

## 六、跨城市复用时的"机械移植"残留（实战踩坑）

用已有方案做模板生成新城市方案时，最容易把旧城市的专属内容带过去：

- **地标张冠李戴**：深圳版写"市民中心大鹏展翅"，生成广州版时原文保留成了"花城广场可看大鹏展翅式建筑群"——广州根本没有这个建筑。**做法**：生成新方案后，全文搜索旧城市的专属地标/人物/事件名（如大鹏展翅、春笋、前海、APEC），逐处核实是否属于新场景。
- **日期/天气自相矛盾**：广州版同一板块写"约 10–20℃"又写"历史同期约 9–20℃"。**做法**：数字出现两处时核对一致性。
- **重复安排**：首日已逛花城广场，次日路线 B 又写"逛花城广场"。**做法**：对照两日行程，检查景点是否重复；重复时改成"换个角度/不同体验"并说明。
- **诗句韵脚混乱**：七律偶数句押韵，广州版曾出现"城/情/生/城/情"重复韵脚。**做法**：按 content.md 的七律规则检查韵脚，避免同一韵字重复。
- **路线返程车站笼统**：广州版曾写"从广州站/广州南站返深"，两站相距很远。**做法**：返程写清具体用哪个站及原因。
- **酒店位置夸大**：把"广州东站商圈"的酒店写成"步行可达珠江新城"（实际约 3 公里）。**做法**：位置描述核实距离，用"地铁 N 站"而非"步行可达"。
- **地图缺失**：广州版初版只有图例文字没有地图截图，与深圳版风格不一致。**做法**：按 map.md 为每条新方案配图；图例、截图、在线地图编号三处一致。

## 七、绿色标注与图组去重的实战教训

- **绿色要标地名，不标"网红打卡"字样**：一览表与打卡地一览里，把 `<span class="apec">花城广场</span>` 这类**地名**加粗加绿；不要只把"网红打卡"四个字加绿——那等于没标出到底是哪个点。打卡地一览这类整章都是打卡地的表格，其"类型"列不必加绿，但"地名"列应加绿。
- **图组换图必须去重**：同一图组里 1 大 3 小应是 4 张不同画面。曾出现小图 1 与小图 3 完全相同（都是"广州塔夜景+紫花"）、小图 2 带大段文字水印。做法：拼 contact sheet 目视核对，重复或带水印的图直接剔除，从小红书补搜"音乐喷泉/白天广场/东西塔"等不同视角。
- **修改后要验证 DOM 而非只看文本**：预览工具会给元素注入 `data-page-node-id`，纯字符串替换 `<span class="apec">…` 常匹配不到带属性的实际标签。给已有 `<b>` 加 class 或改用正则兼容属性；改完用 `document.querySelectorAll('.apec').map(e=>e.innerText)` 确认标的是地名。
- **跨日景点不要重复主打**：首日已重点介绍广州塔，次日就不该再做"广州塔线"。把次日改为"珠江江心线（海心沙→海心桥）"这类互补主题，正文与图片同步替换。
- **上午时段不写"夜景"**：11:30 的事件写"花城广场夜景"是时间矛盾，改成"白天街景/慢走"。
